## 四、未验证项（需要用户配合时再补）

1. **无 Python 的干净 Windows 10/11 x64 机器**上运行便携目录与安装包：需要虚拟机或独立机器。
2. **真实 LLM API 翻译**：需要 `.env` 中的 Base URL、模型名与 Key；当前所有“真实引擎”验证都是 `skip_translation` 模式（验证了版面推理、排版、字体与 PDF 产出，但没有真实翻译文本）。
3. **交互式界面点击**：拖拽多文件、非法页码高亮、关闭窗口三选项——逻辑均有接口/单元测试覆盖；界面骨架已有 2 项组件测试（标题、标签页、设置入口、未配置 API 时的引导），但没有做真实拖拽与点击的端到端自动化（本机浏览器自动化通道不可用）。

   另记录一个已修复的真实缺陷：冻结版双击启动（无控制台，`sys.stdout` 为 `None`）时 uvicorn 日志初始化抛异常、进程在建窗口之前退出。修复提交 `016fa6d`（标准流兜底 + 关闭 uvicorn 自带日志配置 + 启动标记 + 崩溃日志同时写应用日志目录），并新增 7 项回归测试。
4. **离线（断网）启动 + 完整资源包**：需要构造断网环境。
5. 安装包本体：`installer.iss` 已提供，但本机没有安装 Inno Setup，**未实际编译**。
