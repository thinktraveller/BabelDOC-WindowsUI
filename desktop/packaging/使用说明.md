# BabelDOC 本地翻译工作台 · 使用说明

## 1. 这是什么

把 BabelDOC PDF 翻译引擎包装成本地 Windows 中文工作台：在界面上配置 API、导入 PDF、
排队翻译、查看真实进度、取消或重新执行、管理成果与术语表。所有文件都保存在本机，
只有调用你自己配置的 LLM 服务与下载模型资源时才需要联网。

## 2. 运行要求

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 21H2 及以上 / Windows 11（64 位） |
| WebView2 | 系统通常自带；缺失时界面会提示安装 Microsoft Edge WebView2 Runtime |
| 磁盘 | 建议 ≥ 5 GB（模型与字体缓存在 `%USERPROFILE%\.cache\babeldoc`，译文与任务数据在应用数据目录） |
| 网络 | 调用你自己配置的 LLM 服务时需要联网；便携目录／安装包首次使用需下载模型与字体或导入离线资源包；单文件完整版内置这些资源 |
| Python | **不需要**，交付包内含运行时 |

## 3. 交付形态

- **单文件完整版**：`BabelDOC-WindowsUI.exe` 可单独复制到桌面或其它目录运行。内含 Python 运行时、前端、版面模型、字体、tiktoken 和 CMap；首次启动会将资源恢复到用户缓存，之后复用。运行时会在系统临时目录解包，启动可能比便携目录慢。
- **便携目录**：解压后双击 `BabelDOC.exe` 即可，不写注册表、不需要管理员权限。
  必须保留整个目录；只复制目录中的 `BabelDOC.exe` 会缺少 `_internal` 等依赖。若只想在桌面放图标，请创建指向该 EXE 的快捷方式。
- **安装包**：`BabelDOC-Setup-*.exe`，安装到 `%LOCALAPPDATA%\Programs\BabelDOC`，创建开始菜单快捷方式（桌面快捷方式可选）。
  卸载默认**保留**你的数据，卸载结束时会提示数据目录位置。

## 4. 首次启动

1. 双击 `BabelDOC.exe`，窗口打开后先看到「翻译工作台」。
2. 若缺少模型或字体：点右上「环境自检」查看缺失项，回到「设置 → 资源」点「下载缺失资源」重试；
   网络受限时改用「导入离线资源包」。
3. 在「设置」里添加 API 配置：名称、Base URL（例如 `https://api.example.com/v1`）、模型名、API Key。
   API Key 只写入 **Windows 凭据管理器**，数据库与日志都不保存明文。
4. 点「连接测试」确认可用：会区分认证失败、地址不可达、模型不存在、超时、参数不兼容等情况。

## 5. 翻译一份 PDF

1. 在「翻译工作台」把 PDF 拖进上传区（可多选），点「导入选中文件」。
2. 勾选要翻译的文件；选择 API 配置；按需填写参数（常用参数直接可见，高级参数在折叠区）。
   - 页码范围例如 `1-5,8`，留空表示全部；填写超出文档页数会在提交前被拦下。
   - 参数预设可保存复用；预设只保存参数，不保存 Key。
3. 点「提交翻译任务」，到「任务与文件」查看状态：排队中 → 翻译中（显示阶段与处理进度）→ 已完成。
4. 任务详情里可以「打开」成果、另存为、在文件夹中显示；若成果被移动或删除，会标注“文件不存在或被移动”并给出一键重新执行。

## 6. 术语表

1. 任务如果开启了「自动提取术语」，会产出 `*.glossary.csv`；在「术语表」页用「从任务导入」把它变成待审核条目。
2. 也可以直接导入 CSV（需要 `source,target` 两列，可选 `tgt_lng`）。
3. 同一个源词 + 目标语言出现不同译词时**不会静默覆盖**：条目会标为「冲突」，你需要选择「保留当前」或「采用新值」。
4. 冲突清零后点「生成版本」得到不可变快照；之后在工作台选择该版本，任务就会带着这份术语表运行。
   运行中的任务使用提交时的版本快照，之后再改术语不会影响它。

## 7. 取消、中断与重新执行

- **取消**表示停止当前任务并清理未完成输出，**不是暂停**，不保留断点；取消后不会标记成功。
- 关闭窗口时若还有任务在跑，会问你怎么处理：等待完成 / 取消任务并退出 / 结束并标记为已中断。
- 应用异常退出（断电、任务管理器结束进程）后重启，未完成的任务会被标为「已中断」，**不会自动重跑**；
  已有成果文件会保留，但可能不完整，需要你决定是否重新执行。

## 8. 文件与数据放在哪里

| 内容 | 位置 |
| --- | --- |
| 应用数据（数据库、任务目录、日志） | `%LOCALAPPDATA%\BabelDOC Workbench` |
| 引擎模型、字体、tiktoken 缓存 | `%USERPROFILE%\.cache\babeldoc`（由引擎管理） |
| 你自己导入的原始 PDF | 原位置不动；应用只复制一份到任务目录 |

「任务与文件」里三种删除动作含义不同：删除任务记录（只删数据库记录）、清理任务临时文件（只删 `work`）、
删除应用管理的文件（删任务目录内的输入副本与成果）。**任何删除都不会碰到你原始导入位置的文件。**

## 9. 出问题时怎么排查

1. 「环境自检」页面/命令：`BabelDOC.exe --self-check`（无控制台时会写报告文件到 `%TEMP%\babeldoc-selfcheck-report.txt`）。
2. 「设置 → 导出诊断包」：包含版本信息、任务与参数快照、资源状态与**已脱敏**日志，不含 API Key 与文档正文，便于反馈问题。
3. 日志文件：`%LOCALAPPDATA%\BabelDOC Workbench\logs\workbench.log`。

## 10. 已知限制

- 不承诺所有 PDF 都能无损排版；扫描件（无文字层）会明确报错而不是硬猜。
- 不支持“暂停后从断点继续翻译”；中断/取消后只能重新执行整个任务。
- 单文件版每次启动需要临时解包，首次还会恢复内置资源到用户缓存，因此需要足够的临时磁盘空间；模型与字体仍持久保存在用户缓存，不写入 EXE 所在目录。
- 单文件版不内置系统 WebView2 Runtime，也不内置远程 LLM 服务；缺少 WebView2 时需按界面提示安装，调用 LLM 仍需配置 API。
- 远程 LLM 服务必须联网；完整资源包只解决**模型与字体**的离线准备，不代表可以离线调用模型。
- 首次启动窗口出现约需 10–15 秒（WebView2 初始化 + 依赖加载），之后启动略快；模型首次加载也会比后续慢。
- 杀毒软件可能对 PyInstaller 产物误报；交付目录内提供 `校验值.sha256`，可用于核对文件未被篡改。
