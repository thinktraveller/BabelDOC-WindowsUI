# 从源码构建 BabelDOC 工作台

以下命令从仓库根目录执行。

```powershell
# 1. Python 环境（Python 3.12–3.13，仓库已有 .venv 时可直接使用）
python -m venv .venv
.\.venv\Scripts\Activate.ps1
uv pip install --python .venv\Scripts\python.exe -e .

# 2. 后端与打包依赖
uv pip install --python .venv\Scripts\python.exe "fastapi>=0.115" "uvicorn>=0.32" `
  "python-multipart>=0.0.12" "pywebview>=5.4" "keyring>=25.0" "pyinstaller>=6.11"

# 3. 前端（Node >= 20.18）
cd desktop\frontend
npm install
npm run build
cd ..\..

# 4. 运行（开发）
.\.venv\Scripts\python.exe -m babeldoc_workbench.main --no-window --port 8765
# 浏览器开发模式：desktop\frontend\.env.local 填 VITE_WORKBENCH_TOKEN=<后端打印的 token>，再 npm run dev

# 5. 测试
.\.venv\Scripts\python.exe -m pytest desktop\tests -q
cd desktop\frontend; npm test; cd ..\..

# 6. 打包（目录模式）并组装便携目录
.\.venv\Scripts\python.exe -m PyInstaller desktop\packaging\babeldoc.spec --noconfirm --distpath dist --workpath .tmp\pyi
.\.venv\Scripts\python.exe desktop\packaging\build_portable.py

# 7. 单文件完整版（自动校验/打包模型、字体等离线资源；产物为 release\BabelDOC-WindowsUI.exe）
.\.venv\Scripts\python.exe desktop\packaging\build_onefile.py

# 8. 安装包（需先安装 Inno Setup 6）
iscc desktop\packaging\installer.iss

# 9. 离线资源包
.\.venv\Scripts\python.exe -m babeldoc_workbench.main --pack-assets <输出目录>
.\.venv\Scripts\python.exe -m babeldoc_workbench.main --restore-assets <zip 或目录>
```

`desktop\tests\` 下另有几个可直接运行的验证脚本：

- `smoke_engine.py`：引擎事件流与工作进程（可 `--offline` 跳过 LLM）。
- `verify_service.py`：服务安全边界与前端产物挂载。
- `verify_queue_real_engine.py`：真实引擎走队列（`--lifecycle-check` 额外验证成果操作与分层删除）。
- `verify_recovery.py`：强杀进程后重启的恢复行为。
